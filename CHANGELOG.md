# История изменений

## 28.0.2

- Не создаются сообщения «Удаление предмета» при техническом удалении физических монет во время зачисления в кошелёк (флаг lipatosCurrencyTransfer).
- Настоящее удаление игроками и обычные передачи предметов продолжают регистрироваться.
- Добавлен тест на отсутствие ложного аудита.


## 28.0.1

- Добавлена совместимость с D&D5e 6.0.5.
- Обновлены манифест и установочный архив модуля.
- Рабочая логика модуля сохранена без изменений.

## 28.0.0

- Текущая рабочая версия перенесена в линейку модулей **LipatoS**.
- Внутренний ID изменён с `player-currency-gm-audit` на `lipatos-player-currency-gm-audit`.
- Сохранена логика аудита валюты, предметов, частичных стопок, удалений и Item Piles.
- Сохранены приватные подтверждения игроку и приватный журнал ГМ.
- Добавлена совместимость со старым сокетом `module.player-currency-gm-audit`, чтобы интеграции существующих модулей не сломались при переходе.
